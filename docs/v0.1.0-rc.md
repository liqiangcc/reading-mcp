# v0.1.0 Release Candidate

This branch is the v0.1.0 release-candidate integration branch.

Finalization is intentionally gated by GitHub Actions. The release finalizer must verify, with the committed `Cargo.lock`:

```text
cargo fmt --all -- --check
cargo clippy --locked --all-targets --all-features -- -D warnings
cargo test --locked --all-features
```

It also verifies the real stdio MCP integration and acceptance tests that are part of the normal test suite.

After the source gate succeeds, the finalizer synchronizes the release documentation and removes temporary release-helper workflows. PR creation, merge to `main`, tagging and publishing remain separate explicitly authorized release actions.
